# **BATTERY-BOX PREMIUM HVS / HVM COMBINER BOX** 

Use the Battery-Box Combiner Box for the 

parallel connection of 2 or 3 battery towers. 

- It provides a simple and safe solution for the DC cabling connections. 

- Single DC cable string to the inverter. 



## **BATTERY-BOX PREMIUM HVS / HVM COMBINER BOX** 

- The Battery-Box Combiner Box can be used with the BYD Battery-Box HVS / HVM / HVB / HVM+ / HVS+. 

- Make sure the planned configuration meets the Premium HV 

- Compatible Inverter list by BYD 

- The Towers have the same module quantity. Battery Towers of different models cannot be mixed. 

- The SOC should be the same among all towers upon installation.
